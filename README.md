# SNOWSKY DISC boot layer

An unofficial base layer for the SNOWSKY DISC player, not affiliated with
FiiO or SNOWSKY. Once installed, it lets the player run packages next to its
own software (or instead of its screen interface) and update them as files,
while the player's own system stays intact and a held key at power-on
brings the stock player back.

**Status: in development. There is nothing to install yet.** Installing it
will require writing the player's system memory over USB; that carries a
risk, and the guide that comes with the first release will describe it, the
way back to stock and what packages may do on your player. The way back that
always works is the player's USB Boot, which does not depend on the system
installed: with the player switched off (or its battery run down), hold Volume
Down and connect the cable to the computer.
